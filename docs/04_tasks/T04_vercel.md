# T04 · Live schalten auf Vercel
**Wo:** Du (vercel.com) · **Dauer:** 10 Min · **Verbrauch:** keiner

## Schritte
1. vercel.com → Add New → Project → GitHub Repo `afyanote` importieren.
2. Framework Preset: **Other**. Root Directory: leer lassen (die Datei `vercel.json` setzt `app` als Ausgabeordner).
3. Deploy. Link notieren, z.B. `https://afyanote.vercel.app`.
4. Link im privaten Fenster öffnen, warten bis „Ready offline“ erscheint.

## Falls die Seite leer ist
In den Projekt Einstellungen „Output Directory“ auf `app` setzen und neu deployen.

## Fertig wenn
Live Link funktioniert und zeigt „Ready offline“.
